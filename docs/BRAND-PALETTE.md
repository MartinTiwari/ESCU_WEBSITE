# ESCU website design system

The website uses the approved liquid-themed homepage as its visual reference.
All routes share these tokens from src/app/globals.css.

| Role | Value |
|---|---|
| Navy base | #061D35 |
| Raised navy | #123958 |
| Amber accent and buttons | #F3BE75 |
| Amber text on light backgrounds | #8A4A10 |
| Page background | #F7F6F0 |
| Secondary surface | #EEEAE0 |
| Cream surface | #FCFAF5 |
| Body text | #183047 |
| Muted text | #586979 |
| Borders | #D9DCD9 |
| Error and hazard | #B3401E |

Use Inter for headings, navigation, labels, and body text. Headings are semibold
with tight tracking; labels use restrained uppercase. Amber buttons have navy
text. Use the darker amber token for small text on light surfaces.

Navigation is a consistent 68px cream bar. Inner pages and all product detail
pages use the shared PageHeader with the same liquid artwork, navy overlay,
amber label, and sans-serif heading. The homepage keeps its larger centred hero.
Main content and footer use aligned 1280px containers and responsive gutters.

Buttons have a 48px minimum height and a 2px corner radius. Avoid clipped corners,
blueprint grids, page grain, and molecular scroll decoration. Form errors remain
red; normal controls and focus states follow the navy/amber palette. The WhatsApp
shortcut uses the brand palette while retaining the recognisable icon and label.

This updates the website identity only; existing print artifacts have not been
recoloured. See HOMEPAGE-PHOTOGRAPHY.md for image provenance.
